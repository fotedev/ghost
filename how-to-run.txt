GHOST - Guided Hardware & OS Scrubbing Toolkit
Device identity reset tools. Prefer the interactive launchers
(how-to-run.bat on Windows / how-to-run.sh on Linux); direct commands below.

Windows (PowerShell as Administrator, from the repo root):
  powershell -ExecutionPolicy Bypass -File "src\windows\reset_cursor.ps1"
  powershell -ExecutionPolicy Bypass -File "src\windows\reset_devin.ps1"
  powershell -ExecutionPolicy Bypass -File "src\windows\reset_trae.ps1"
  powershell -ExecutionPolicy Bypass -File "src\windows\reset_qoder.ps1"
  powershell -ExecutionPolicy Bypass -File "src\windows\reset_qoderwork.ps1"
  powershell -ExecutionPolicy Bypass -File "src\windows\reset_zcode.ps1" -Target Primary
  powershell -ExecutionPolicy Bypass -File "src\windows\reset_zcode.ps1" -Target Secondary
  powershell -ExecutionPolicy Bypass -File "src\windows\reset_zcode.ps1" -Target Both
  powershell -ExecutionPolicy Bypass -File "src\windows\launch_zcode_second_instance.ps1"
  powershell -ExecutionPolicy Bypass -File "src\windows\reset_minimax_opencode.ps1"
  powershell -ExecutionPolicy Bypass -File "src\windows\change_device_id.ps1"

Or double-click: how-to-run.bat

ZCode captcha watchdog (unattended; runs as your user, no admin needed):
  powershell -ExecutionPolicy Bypass -File "tools\watch_zcode_captcha.ps1"
Telegram escalation reads TELEGRAM_BOT_TOKEN / TELEGRAM_CHAT_ID from .envlocal
(repo root; git-ignored). Test first:
  powershell -ExecutionPolicy Bypass -File "tools\watch_zcode_captcha.ps1" -RunOnce -DryRun
NOTE: the watchdog monitors the PRIMARY instance only.

ZCode dual-instance (two independent windows/accounts, Windows only):
  powershell -ExecutionPolicy Bypass -File "src\windows\launch_zcode_second_instance.ps1"
First launch clones history into %USERPROFILE%\ZCodeSecondHome, scrubs it to
fresh IDs, and routes Telegram channel bots to Primary (one-time, automatic).
Both instances share one install, so one update covers both.

Linux:
